Starfall Spires is a real-time 3D card battler: pick a deck of crystal constructs, spend regenerating starlight to deploy units, structures and spells on a floating arena, and raze the enemy keep before yours falls. An AI rival plays its own cards in real time, defends its towers and pushes back harder as the match runs on. Built with Three.js (primitives only, no external assets), an HTML card hand, and synthesized WebAudio sound.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome. Click a card (or press 1-4), then click your half of the arena to deploy. P pauses, R restarts, M mutes.
